# D-074 — ADR-0027 Alternative A 제목 정정

## 명제
Alternative A 제목이 Decision의 base `limits.cpu: 2000m` / `requests.cpu: 250m`와 모순되거나 Alternative C의 base 500m 유지안과 혼동되면 미완이다.

## 전제 검증과 범위
현재 `k8s/base/infra/mysql/mysql.yml`은 requests 250m / limits 2000m이고 Decision도 같다. Alternative A 제목에만 "base 500m 유지"가 섞여 있다. 단일 문서 오기이며 계약·결정 변경이 없어 S. ADR 인덱스의 사실 오류 정정 예외에 따라 제목 정정과 Update Log만 변경한다.

## 작업 항목
- [x] P1. 제목을 base limits 2000m / requests 250m 유지로 명시하고 Update Log에 날짜·변경 대상 기준 커밋·미커밋 상태와 사유 기록.
- [x] P2. Decision·Alternative C·실제 CPU 설정과 대조하고 diff가 제목 1줄 및 Update Log에만 한정되는지 확인.

## 검증
`git diff --check`, 원문에서 제목 1줄 치환한 결과가 Update Log 이전 본문 전체와 정확히 같은지 대조, YAML의 MySQL requests/limits 실값 확인. 문서 변경으로 별도 Gradle 실행 없이 메인 최종 검증에 포함한다.

## 미해결 / 후속
초기 구현 때 제외했던 커밋·push·PR을 후속 사용자 요청으로 수행했다. 정정 커밋 `6fc9d04`는 `fix(adr):` 규약을 따르며 Update Log에 실제 커밋 정보를 반영했다. 별도 Codex 리뷰 미호출.

# D-063 — 무료 로컬 실제 Grafana/Prometheus alert 평가

## 명제
실제 series와 evaluator 없이 정적 통과를 발화로 주장하거나, for를 줄이거나, NoData를 정상 복귀로 처리하면 미완이다.

## 배경과 동등성 판단
독립 검증자의 환경 동등성 조사(`/private/tmp/peakcart-verifier-d063-equivalence.md`)는 ADR-0015와 PHASE4가 요구한 것이 실제 Prometheus/Grafana 평가이며 GKE 자체는 불변식이 아님을 확인했다. 기존 shared rule 파일 범위는 평가/UI 상태까지이고 외부 전달은 제외다. 따라서 무료 로컬 실제 바이너리+fixture로 완료 조건을 충족할 수 있다. 실제 실행 증거 전에는 완료가 아니다.

새 production 인프라·제품 계약은 추가하지 않고 재현용 로컬 도구를 추가하므로 M. ADR 결정 변경 없음. Grafana 공식 provisioning 문서(https://grafana.com/docs/grafana/latest/administration/provisioning/)와 alert API 문서(https://grafana.com/docs/grafana/latest/alerting/set-up/provision-alerting-resources/http-api-provisioning/)를 확인했다. 이미지 tag는 고정하고 실행 시 digest·version을 기록하며 GKE 바이너리와 동일하다고 주장하지 않는다.

## 작업 항목
- [ ] P1. 정본 전체 provisioning, source SHA/hash, 실바이너리 버전/digest, loopback 포트와 고유 compose project로 재현 하네스 준비·독립 검토.
- [ ] P2. 잘못된 application/status/operation·0값·짧은 breach 음성 대조 및 두 실제 exporter 인스턴스 검증.
- [ ] P3. 원래 15m/10m/5m/get10m/evict0s 유지, 각 서비스와 캐시의 Normal→Pending→Alerting→Normal/실제query/평가시각 증거.
- [ ] P4. 컨테이너 cleanup, 결과 artifact 요약/audit, 전체 CI·독립 검증·root 병합·완료기록.

## 검증 방법
`python3 scripts/monitoring/verify_alerts.py --output <새 경로>`는 준비만 한다. root heavy 슬롯 승인 후 clean commit에서 `--run`으로 실제 실행한다. baseline120s, transient90s, 복구390s, sustained1080s, 복구390s이며 for/평가1m을 가속하지 않는다. 별도 2 exporter가 같은 서비스의 독립 instance 라벨을 공급한다. 잘못된 라벨 양성 series 존재를 Prometheus로 확인하면서 정상 규칙은 inactive여야 한다. rate/increase에는 baseline후 최소2samples를 확보한다. 마지막값0과벡터존재·Grafanahealth를 같이 확인해 NoData복귀를 막는다. 원본과 provisioned모델/for/labels를 대조한다.

## 미해결과 범위
GKE ServiceMonitor발견/ConfigMap sidecar전달/실앱메트릭방출/운영장애/외부알림은 검증하지 않는다. 이전 역사 기록은 보존하고 환경경계만 추기한다. DockerHub 무료 이미지 pull 한도·접근 실패 시 우회하지 않고 보류한다. 로컬실행 및독립검증전 완료표시금지.

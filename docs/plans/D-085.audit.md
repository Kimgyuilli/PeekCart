# D-085 audit

## 2026-10-21 02:46 KST — 계획 및 구현 검증

- 등급: M. 공유 CI 정책 검사 계약 변경이며 ADR-0030의 기존 전파 결정을 집행한다. 새 ADR 불필요.
- 상태: 별도 Codex 리뷰 미호출. 독립 검토 대상 SHA와 결과는 root가 후속 기록한다.
- 코드 전제: origin/main `eb5dee5`의 정규식 기반 CRG-003은 각 비교 문자열의 존재만 확인하며 step `continue-on-error`는 확인하지 않는다.
- 구현: 제한 문법 파서(괄호·불리언·`cancelled()`·결과 문자열 비교·NOT/AND/OR)와 의미 평가기를 사용한다. 암묵적인 `success()` 삽입을 피하려고 명시적인 상태 함수를 요구한다. 알 수 없는 문법은 CRG-003으로 거부한다.
- 직접 재현: 임시 디렉터리에 실제 workflow를 복사해 OR 전체를 AND로 교체하거나 전파 step의 `continue-on-error`에 `true`/`${{ true }}`를 추가했다. 각 변이는 원본 lint에서 rc=0, 수정 lint에서 rc=1 및 CRG-003이다. 작업 트리의 workflow는 변경하지 않았다.
- 통과: `bash -n scripts/ci-release-gate-lint.sh`, 정상 lint, self-test(55/55 변이, 정상 workflow 6개, 독립 파서 사례 6개, 정상 조건식당 2,048개 결과/취소 조합).
- 통과: ci-e2e-parallel-lint 정상 및 self-test 7/7, ci-test-matrix-lint 정상(11개 모듈·6개 shard) 및 self-test, `git diff --check`, consistency precheck(ok, exit 0).
- 대기: GitHub Actions 전체 CI의 동일 SHA 결과. 로컬 `./gradlew test`는 병렬 중복 실행을 피하고 동일 SHA의 CI all-module test/guards/images/e2e 결과로 검증한다. draft PR 생성은 root의 명시적 지시로 진행하며 CI 대기를 통과로 기록하지 않는다.
- 범위 밖: GitHub Actions 식 전체 지원과 run 셸 의미 분석. 기존 run의 `exit 1` 문자열 검사를 확장하지 않았다. 전파 step의 동적 `continue-on-error`는 평가 추측 대신 거부한다.

# D-066 상품 정렬과 캐시 키

## 명제

서로 다른 정렬의 목록 결과가 같은 캐시를 공유하거나 동률 결과 순서가 불안정하면 미완이다.
단일 상품 모듈 공개 API 계약 변경으로 M. ADR-0037을 따른다.
코드 확인: Controller PageableDefault에 sort 없음, ProductCacheService key에서 pageable.sort 누락.

## 작업 항목

- [ ] P1. id ASC 기본값, id/name/price allowlist와 id ASC tie-breaker, 400 거절을 추가한다.
- [ ] P2. 정규화된 정렬을 캐시 키에 포함하고 양방향 캐시 오염·동률·invalid sort를 검증한다.
- [ ] P3. 최신 전체 CI·독립 검증·root 병합/기록을 확인한다.

## 검증

실제 Redis/MySQL에서 price DESC 먼저/default 다음과 반대 순서 모두 기대 id 순서를 확인한다.
동률 가격·이름 상품의 id tie-breaker와 다음 페이지 경계를 확인한다. 잘못된 필드는 repository 호출 전 400.
부모 PR177은 미병합이며 최신 main 통합 후 재검증한다. 커서 전환은 범위 밖이다.

# D-051

PR: [#163](https://github.com/Kimgyuilli/PeekCart/pull/163)

## 명제
Layer 1 문서나 CLAUDE.md 에 코드에 없는 경로·클래스·신호 경로가 현재 상태로 적혀 있으면 미완이다.

## 작업 항목
- [x] P1. `02-architecture.md` Phase 4 트리의 `common/` 블록(존재하지 않는 `com/peekcart/common/{event,outbox,idempotency}`)과 존재하지 않는 `OrderEventProducer`·`PaymentEventProducer`·서비스 내 `slack/SlackNotificationClient` 를 실제 배치로 정정한다. 실제로는 이벤트 DTO 가 `common` 의 `global/outbox/dto/` 에서 공유되고, Outbox·멱등성·DLQ 원장은 서비스별 `global/{outbox,idempotency,deadletter}` 에 복제돼 있다(D-049)
- [x] P2. 같은 문서 §Phase 1→4 표의 이벤트 DTO·Outbox 행(542-543)을 P1 과 같은 사실로 정정한다
- [x] P3. `04-design-deep-dive.md` §8-3 step 3 과 이를 인용하는 §한계 절(506행)의 "DLQ → Slack 알림" 을 §9-3 과 일치시킨다. 주 신호는 원장 적재 + `peekcart-dlq-backlog` alert 이고, Slack 은 best-effort 보조 신호로 notification 만 실제 발송한다(나머지는 no-op, see ADR-0018)
- [x] P4. `CLAUDE.md` 명명 규칙의 `{Domain}EventListener (infrastructure/event)` 를 실제 규약 `{구독 대상}Consumer (infrastructure/kafka)` 로 바꾼다

## 검증
- `grep -rn "com/peekcart/common\|common/event\|common/outbox\|{Domain}EventListener\|EventProducer" CLAUDE.md docs/0[1-7]*.md` 결과가 0건이어야 한다
- 정정 후 문서에 적힌 경로를 `ls`/`find` 로 하나씩 대조해, 없는 경로가 하나라도 나오면 미완으로 본다
- 문서에서 DLQ 신호를 설명하는 곳에 "Slack 알림" 이 주 신호로 남아 있는지 `grep -n "Slack" docs/04-design-deep-dive.md` 로 확인한다

- Outbox 복제 해소 자체는 D-049 에서 다룬다

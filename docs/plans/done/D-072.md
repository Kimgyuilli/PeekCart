# D-072 캐시 hit의 MySQL 세션 명령 제거

## 명제

상품 cache hit이 MySQL 명령을 전송하거나 cache miss DTO 생성이 트랜잭션 밖에서 실행되면 미완이다.
단일 상품 모듈 트랜잭션 계약 변경으로 M, ADR-0037을 따른다.
코드 확인: ProductQueryService 클래스 readOnly가 cache proxy를 감싸며 CacheConfig advisor order 미지정.

## 작업 항목

- [x] P1. 조회 facade 트랜잭션 제거, cache advice order 명시, miss의 기존 readOnly 경계 유지.
- [x] P2. 실제 proxy advisor 순서 및 MySQL general_log의 hit 0/miss 양성 대조를 검증한다.
- [x] P3. 기존 캐시 직렬화/정렬 회귀, 최신 전체 CI·독립 검증·root 병합/기록.

## 검증

Hibernate prepared statement 수에 세션 명령이 빠지는 문제를 서버 general_log로 보강한다.
기존 shared MySQL에서 root 연결로 log를 켜고 측정 구간 뒤 원래 설정을 복구한다.
측정 연결 자신의 명령은 thread_id로 제외하고 실제 앱 DB 명령 전체를 센다.
GKE 성능 인과/배속 검증은 제외 D-078이며 로컬 결과로 대신하지 않는다.

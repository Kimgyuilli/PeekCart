# D-053 — Layer 1 문서의 Phase 1·2 설계 아카이브

## 1. 명제

아래 중 하나라도 성립하면 미완이다.

- `docs/02-architecture.md` 나 `docs/05-data-design.md` 에 Phase 1·2 시점의 다이어그램, 패키지 트리, ERD, Phase 1 대비 비교표가 남아 있다. 문서 레이어 원칙상 Layer 1 은 현재 상태(What)만 적는다
- 옮긴 내용이 어디에도 남지 않거나, 옮기면서 바뀐다
- 옮긴 뒤 밖에서 이 두 문서를 가리키는 참조(절 번호 · 하위 절 이름)가 가리킬 곳을 잃는다
- `docs/consistency-hints.sh` 항목 4 가 `TASKS.md` 에 이제 존재하지 않는 완료 행을 찾는다 (D-052 미충족 이월)

인바운드 참조(34개 파일)는 절 번호(§5 · §11 · §12)나 남는 하위 절(§5 Phase 4 다이어그램, §11 Phase 4 ERD, §12 배포 절차 · 패키지 구조)을 가리킨다. `CLAUDE.md:101`, `k8s/base/kustomization.yml:9`, `k8s/monitoring/*/install.sh:7`, ADR-0006 · 0010 · 0012 · 0016, `phase4-design-roadmap.md:17` 이 그렇다. 절 제목을 유지하므로 깨지는 참조는 없다. `.md#` 앵커 링크는 0건이다.

예외는 ADR-0010:17 `(L95-164)` 과 ADR-0012:28 `(L174-382)` 의 줄 번호 참조다. 이미 현재 줄과 어긋나 있고, ADR 은 immutable 이라 고치지 않는다.

옮길 곳은 `docs/progress/design-archive-phase1-2.md` 한 파일이다. 두 문서에서 온 절을 출처(문서 · 절)별로 묶는다. Layer 1 쪽에는 옮긴 자리마다 포인터 한 줄을 남긴다. ADR 선행 판단: 외부 의존 · 경계 · 인프라 변경이 없다.

## 2. 작업 항목

- [x] P1. `docs/progress/design-archive-phase1-2.md` 를 만든다. 머리에 아카이브 안내(분리 일자 · 출처 · 현행 위치)를 두고, 위 표의 "아카이브로 이동" 구간을 출처 절 제목 아래 원문 그대로 옮긴다. 출처는 `##` 헤딩으로 두고, 옮긴 `###` 헤딩은 레벨을 바꾸지 않는다(구현 중 정정: 레벨을 내릴 필요가 없었다)
- [x] P2. `02-architecture.md` 에서 해당 구간을 지우고 §5 · §12 에 포인터 한 줄씩 둔다. §12 머리 인용문을 현재 구조(Phase 4 멀티모듈) 기준으로 다시 쓴다
- [x] P3. `05-data-design.md` 에서 해당 구간을 지우고 §11 머리에 포인터 한 줄을 둔다
- [x] P4. `docs/consistency-hints.sh` 항목 4 와 머리 주석의 항목 4 줄을 지운다. 종료 메시지의 "항목 1·3·4" 도 맞춘다

## 3. 검증 방법

- **V1 (보존)**: 이동 전 두 문서의 비어 있지 않은 줄을 **개수까지** 세어, 이동 후 두 문서와 아카이브의 개수 합이 모자라지 않는지 python 으로 비교한다. 줄 집합 비교는 ERD 의 `bigint id PK` 처럼 반복되는 줄의 누락을 놓친다(구현 중 주입으로 확인하고 정정). 예외는 다시 쓴 §12 머리 인용문뿐이고 목록으로 명시한다. 주입: 아카이브에서 ERD 한 줄을 지우고 돌려 누락 1건이 잡히는지 본다
- **V2 (잔존)**: 두 Layer 1 문서에서 `^### Phase [12] ` 헤딩과 `Phase 1 vs`, `Phase 1 → Phase 4` 헤딩이 0건이다
- **V3 (참조)**: §2 표의 인바운드 참조가 가리키는 절 제목(`## 5.`, `## 11.`, `## 12.`, §5 `### Phase 4 — MSA`, §11 `### Phase 4 — 서비스별 DB 분리`, §12 `### Phase 3 — 인프라 매니페스트`)이 전부 남아 있다. 주입: 하나를 지우면 검사가 잡는다
- **V4 (mermaid)**: 두 Layer 1 문서와 아카이브에서 ```` ```mermaid ```` 와 닫는 펜스 수가 짝이 맞는다. 잘린 코드 블록은 뒤 문서 전체를 코드로 렌더링한다
- **V5 (hints)**: `bash docs/consistency-hints.sh` 가 항목 1~3 을 출력하고 exit 0 이다. 출력에 "TASKS.md 완료 Task" 가 없다

## 미해결

- 02 §12 `### Phase 3 — 인프라 매니페스트` 의 디렉터리 트리는 루트 `src/`("Phase 1·2 에서 구축된 애플리케이션 코드")를 그리는데, 멀티모듈 전환으로 루트 `src/` 는 없어졌다. 절 자체는 현행 배포 순서의 정본이라 이번에 옮기지 않는다. 트리 정정은 행 범위 밖이며 별도로 다룬다

# D-095

## 명제
ADR-0032가 공유 Java DTO의 컴파일 보장을 JSON 필드 호환성 보장으로 과장하거나 Pact 필요성을 입증된 결론처럼 적으면 미완이다.

## 작업 항목
- [x] P1. ADR Update Log에 Java 타입 공유와 직렬화된 wire 필드 호환성의 증거 경계를 기록한다.
- [x] P2. 현재 검증 안내에 해당 경계를 좁혀 반영하고 문서 검사를 통과한다.

## 검증
양성 및 `@JsonProperty("recipientId")` 변이 XML, compile 로그, NotificationConsumer의 `JsonNode.get("userId")`를 대조한다. 변이에서도 `userId` 호환성이 컴파일만으로 보장된다고 읽히거나 Pact 채택이 필수라고 단정하는 문구가 남으면 실패다.

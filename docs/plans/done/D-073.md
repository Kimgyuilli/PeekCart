# D-073 — 원본 측정·코드 이력 정정

## 명제
관찰과 인과 실험, CPU 수집 런과 처리량 런을 혼동하거나 원본 없는 표면까지 완료로 선언하면 미완이다.

## 배경과 ADR 판단
문서 사실 정정만 수행하며 결정·실행 계약 변경 없음, 모듈 변경 없음, 되돌림 국소이므로 S다. ADR-0025/0027 결정은 보존하고 사실 정정을 추기한다. 원본 세션을 직접 읽어 CPU 수집의 70초 런과 358.5 rps의 직전 60초 런도 구분했다(기존 TASKS 표현보다 엄밀한 정정).

## 작업 항목
- [x] P1. 원본 2026-09-15 세션·7cadfa0 호출 체인·로컬 #119/#120 squash commit 대조 및 증거 문서화.
- [x] P2. 기존 evidence·ADR·archive plan·PHASE4·TASKS archive/done에 원문 보존 정정 추기와 안내 추가.
- [x] P3. root가 제공한 블로그 28편 원본 대조: 이미 정정된 CPU 관찰·모놀리스 역전 설명 확인, 외부 수정 불필요.
- [x] P4. 최신 CI gate·독립 PR 검증·root 병합 및 완료 기록.

## 검증
원본 JSONL UTC 시각/행의 명령과 결과를 분리해 읽는다. 낮은 VU CPU 표본을 400 VU 표본이라고 대입하면 정정 근거 표와 충돌한다. 7cadfa0에서 OrderCommandService 클래스 트랜잭션부터 InventoryService까지 호출을 직접 따라간다. immutable 문서 원문 보존을 git diff로 확인하고 git diff --check를 수행한다. 전체 CI는 사용자 승인에 따라 필수 gate로 대체한다.

CPU 표본과 처리량 런, 코드 호출 체인과 PR119/120 이력을 원본 대조해 정정했다. 블로그28편은 이미 정확해 외부 수정하지 않았다.

2026-10-17 [PR177](https://github.com/Kimgyuilli/PeekCart/pull/177) 병합 SHA `850b0d448ebc6e46524aa2576545b3d55c1ff9d6`. PR head `cb58da0944fc49ee14756f307328662f8bcca39a`, base `3e1ba64c715d22b1f5a2d2635a97da17eb4ebb28`, 실제 checkout `4bde8cced2ff8b4ec43bc6a476bcda59ef4cbdbb`의 [CI38981159191](https://github.com/Kimgyuilli/PeekCart/actions/runs/38981159191)는 필수17jobs/gate와 XML229/1296tests 실패·오류·skip0, 양E2E 이미지 identity/동일SHA A–E/음성 대조군을 통과했다. 독립 verifier가 최신 head/base와 실제 checkout 부모, artifact를 대조해 PASS를 기록했다.

병합 후 [main CI38982636776](https://github.com/Kimgyuilli/PeekCart/actions/runs/38982636776)는 실제 checkout850b0d4, 같은1296tests와 양E2E, gate를 포함한23jobs 및6publish 모두 성공했다. 공개 GHCR6서비스의 SHA태그/latest manifest digest와 config 일치도 독립 확인했다. root만 보호 규칙을 지켜 병합했으며 별도 codex exec 리뷰는 호출하지 않았다. 무료 조건은 공개 저장소·표준 runner·GHCR 확인 및 사용자의 artifact/cache 무료 범위 확인으로 충족했다.

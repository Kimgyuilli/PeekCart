# D-080 통합 테스트 기동 비용 서술 정정

## 1. 명제

XML time과 task 시간 차이를 모두 기동 비용으로 귀속하거나 원본을 확인하지 않은 발견 이력을 확정하면 미완이다.
공용 테스트 규약 문서 계약을 정정하므로 M. 런타임 동작·기존 ADR 결정은 바꾸지 않는다.

| 코드/원본 전제 | 확인 결과 | 처분 |
|---|---|---|
| SharedContainers/AbstractIntegrationTest/CLAUDE/lint | 클래스당 31초 또는 844초 전부 기동 비용이라고 서술 | 기동·종료 대기 분리로 정정 |
| CI 35731821466 XML/log | 58 XML time 합 131.202초, 마지막 클래스 종료 추정 뒤 약 515초 | 근거 표·hash 보존 |
| E1/E1b XML/log/jstack | 종료 꼬리 479.5초/92.3초, Spring shutdown lifecycle await | 총 시간 개선으로 일반화하지 않음 |
| 실제 Boot/Testcontainers jar | CacheKey container 객체 및 GenericContainer identity equals | 포트 변경을 캐시 키 원인으로 적은 ADR에 정정 추기 |
| 순차 run1/3/5 실패 | 원본 JSONL 1287/1386/1465, 셔플 도입1592 이전 | 결함4 최초 발견 이력 정정 |

ADR 판단: 기존 ADR-0028의 사실 정정이므로 새 ADR 없이 Update Log 추기. immutable 이력은 삭제하지 않는다.

- [x] P4. root가 TASKS-done의 실제 구현명 정합화 및 전체 CI/독립 검증·병합·최종 기록을 처리한다.

## 3. 검증 방법

- docs/evidence/D-080/class-timings.tsv는 원본 XML timestamp/time/test 결과와 각 파일 SHA-256. 원본 경로·task 경계·log hash는 README에 기록한다.
- 독립적으로 timestamp+time의 마지막 종료를 계산해 task 끝과 비교한다. 클래스 시간 합과 task 시간을 혼동한 설명은 이 비교로 반증된다.
- javap로 Boot 3.5.12 CacheKey와 Testcontainers 1.21.4 GenericContainer.equals의 실제 구현을 확인했다.
- integration-test-container-lint, diff check, consistency precheck를 실행한다. 런타임 코드는 변경하지 않는다.

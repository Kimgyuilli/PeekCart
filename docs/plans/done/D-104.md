## 3. 검증

고정 git source에서 재계산하고 매치별 파일/줄을 남겨 숫자와 모집단을 독립 대조할 수 있게 한다. 전체 리뷰 원문을 되살린 것으로 표현하지 않는다. shell 주석 외 내용 동일성 및 syntax, docs-preservation gate를 경량 확인하고 전체 CI는 Actions 우선이다. 새 source/운영/유료모델/Gradle/Docker 실행은 없다. 별도 Codex 리뷰 미호출. 공유 TASKS/master 및 위임되지 않은 PHASE4 문장은 편집하지 않는다.

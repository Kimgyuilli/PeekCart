# D-067 요청 타입 및 메서드 검증 오류 응답

## 1. 명제

클라이언트의 경로/쿼리 타입 오류나 입력 메서드 검증 실패가 500으로 응답하거나 서버 반환값 검증 실패를 400으로 숨기면 미완이다.
common과 소비 서비스 테스트 여러 모듈, 공유 에러 계약 변경이므로 L.

| Product/AdminProduct/Order/Cart/Payment | Long 경로 파라미터 사용 | 실제 컨트롤러 경로의 잘못된 id 슬라이스 회귀 |
| 기존 비즈니스/본문 검증 | 별도 핸들러와 기존 테스트 | 유지 |

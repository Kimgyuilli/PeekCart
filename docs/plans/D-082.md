# D-082 — 자율 writer 수명 lint (D-081 공동 구현)

## 명제 / 코드 검증
writer opt-in 또는 명시적 리스너 수동 기동 클래스가 AFTER_CLASS 수명 없이 lint를 통과하면 미완이다.

| 코드 전제 | 확인 결과 |
|---|---|
| ADR-0029 D3 / CLAUDE | writer opt-in은 DirtiesContext(AFTER_CLASS) 필요 |
| 현재 테스트 | 속성 opt-in 클래스 및 수동 DLQ 기동 클래스에 AFTER_CLASS 존재 |
| container lint | DirtiesContext 검사 없음 |

여러 모듈 테스트에 적용되는 공유 lint 계약 보강이므로 M. ADR-0029 기존 결정을 집행하며 별도 ADR 불필요. 별도 Codex 리뷰 미호출.

## 작업 항목
- [x] P1. D-081의 동일한 writer 탐지로 ITC-007 추가. 클래스 DirtiesContext 기본 AFTER_CLASS 또는 명시적 AFTER_CLASS 허용, 다른 classMode 거절.
- [x] P2. scheduler/listener/manual opt-in의 누락·잘못된 mode·주석·문자열·메서드 annotation 변이 self-test.
- [x] P3. self-test 및 현 트리 lint 검증.
- [x] P4. 메인 통합 후 전체 ./gradlew test 및 관련 lint 검증.

## 검증
대기 자체는 있는 fixture에서 DirtiesContext만 제거하거나 BEFORE_CLASS/AFTER_EACH_TEST_METHOD로 바꾸면 ITC-007. 주석/문자열/메서드 annotation은 클래스 수명 규약을 충족하지 않는다. 기본 @DirtiesContext와 AFTER_CLASS 명시는 통과. writer가 없는 클래스는 annotation 없어도 통과.

## 미해결 / 범위 밖
상속·사용자 composed annotation은 자동 해석하지 않는다. D-081과 같은 스크립트라 공동 통합한다. 새 ADR 없이 기존 D3 집행 사실은 메인이 공통 문서에 반영한다.

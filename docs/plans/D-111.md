# D-111 — ADR-0025 C 승격 게이트의 허용 범위 수치화

## 1. 명제

다음 중 하나라도 해당하면 미완이다.

- ADR-0025 C 승격 게이트의 "허용 범위"가 지표·산식·표본 규칙 없이 남아 있다.
- 지금까지의 측정이 게이트를 넘는지 판정하지 않았다.
- 판정에 쓴 숫자가 원자료(`loadtest/reports/`)와 대조되지 않았다.
- 측정 조건이 바뀌어 기존 판정이 무효가 되는 경우를 적지 않았다.

배경: ADR-0025 는 "낙관락 충돌률 또는 DLQ 유입이 허용 범위를 넘으면" C(비관적 락)로 승격한다고만 적었다.
2026-10-25 세션(D-108 §5)에서 같은 부하(초당 170건) 비교가 처음 성립했다. 요구사항(`03-requirements.md` §7)에는
주문 실패율 SLO 가 없다. 사용자 결정(2026-11-14)은 다음과 같다.

- 지표는 DLQ/주문으로 정하고 충돌률은 기록만 한다.
- 허용 범위는 0.15%다.
- 새 ADR-0048 로 남긴다. ADR README 규칙상 Consequences 재해석은 Update Log 사유가 아니다.

## 2. 작업 항목

- [x] P1. `docs/adr/0048-inventory-pessimistic-lock-promotion-gate.md` 를 쓴다.
  - 지표와 산식: contend 시나리오(상품 10개·초당 170건·60초·product replicas 3) 유효 run 의 DLQ/주문.
    DLQ 는 product Pod `kafka_listener_recovered_total{topic="order.created"}` 차분이고, 주문은 `order.created` PUBLISHED 건수다.
  - 표본 규칙: 유효 run 2개 이상의 중앙값으로 판정한다. run 1개가 넘은 것만으로는 승격하지 않는다.
  - 허용 범위 0.15%와 그 근거를 적는다. 근거는 SLO 부재, 기준선 0.059%, run 당 5~8건의 Poisson 잡음이다.
  - 충돌률을 기록만 하는 이유를 적는다.
  - 현재 판정: 미달이므로 승격하지 않는다. 표에는 유효 run 과 이전 세션 값을 함께 둔다.
  - 넘었을 때의 절차는 ADR-0025 를 따른다(C 의 DB 비용을 같은 시나리오로 잰 뒤 D1 부분 무효화 ADR).
  - 재측정 조건: 동시 writer 수(파티션·replicas·listener concurrency), 예약 트랜잭션 구성, 재시도 예산·backoff,
    contend 상품 수가 바뀌면 기존 판정은 무효다.
  - Alternatives: 0.1%, 충돌률 병행 게이트, 지금 C 승격.
- [x] P2. `docs/adr/README.md` 색인에 0048 행을 추가한다. ADR-0025 는 Status 를 바꾸지 않는다.
  ADR-0048 은 빈 칸을 채울 뿐 D1~D6 을 대체하지 않는다.
- [x] P3. `docs/04-design-deep-dive.md` §9-1 에 승격 게이트 한 줄과 `(see ADR-0048)` 을 추가한다.

## 3. 검증 방법

- ADR 표의 숫자를 원자료에서 다시 셈한다. scratchpad 스크립트가 `counts.txt`·`prom-delta.tsv` 에서 run 별 DLQ·주문·충돌을
  읽어 비율과 중앙값을 낸다. 그 결과를 ADR 표와 글자 단위로 대조한다. 2026-10-24 값은 `d078-gke-20261024.md` 표와 대조한다.
- 판정 규칙의 false-green 검사: 같은 스크립트에 run 하나의 DLQ 를 16건(0.157%)으로 바꾼 입력을 넣는다. 그러면 단일 run 은
  초과로, 중앙값은 미달로 나와야 한다. 두 run 모두 16건이면 중앙값도 초과로 나와야 한다. 이렇게 표본 규칙이 실제로 갈리는지 본다.
- Poisson 오경보 확률(0.1% 4.3%/1.2%, 0.15% 0.05% 미만)을 같은 스크립트로 다시 계산해 ADR 문구와 맞춘다.
- `python3 -B scripts/docs-preservation-ci.py --base 4a202628c9f5af5dbcf6dd14bfede5ce40365bbb` 와 문서 lint 를 통과시킨다.

- 게이트 계산을 측정 하네스(`d078-s3-export.sh`)에 넣는 자동화는 하지 않는다. 다음 contend 세션의 계획서가 이 ADR 산식을 인용한다.

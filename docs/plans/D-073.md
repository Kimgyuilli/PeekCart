# D-073 — 원본 측정·코드 이력 정정

## 명제
관찰과 인과 실험, CPU 수집 런과 처리량 런을 혼동하거나 원본 없는 표면까지 완료로 선언하면 미완이다.

## 배경과 ADR 판단
문서 사실 정정만 수행하며 결정·실행 계약 변경 없음, 모듈 변경 없음, 되돌림 국소이므로 S다. ADR-0025/0027 결정은 보존하고 사실 정정을 추기한다. 원본 세션을 직접 읽어 CPU 수집의 70초 런과 358.5 rps의 직전 60초 런도 구분했다(기존 TASKS 표현보다 엄밀한 정정).

## 작업 항목
- [x] P1. 원본 2026-09-15 세션·7cadfa0 호출 체인·로컬 #119/#120 squash commit 대조 및 증거 문서화.
- [x] P2. 기존 evidence·ADR·archive plan·PHASE4·TASKS archive/done에 원문 보존 정정 추기와 안내 추가.
- [x] P3. root가 제공한 블로그 28편 원본 대조: 이미 정정된 CPU 관찰·모놀리스 역전 설명 확인, 외부 수정 불필요.
- [ ] P4. 최신 CI gate·독립 PR 검증·root 병합 및 완료 기록.

## 검증
원본 JSONL UTC 시각/행의 명령과 결과를 분리해 읽는다. 낮은 VU CPU 표본을 400 VU 표본이라고 대입하면 정정 근거 표와 충돌한다. 7cadfa0에서 OrderCommandService 클래스 트랜잭션부터 InventoryService까지 호출을 직접 따라간다. immutable 문서 원문 보존을 git diff로 확인하고 git diff --check를 수행한다. 전체 CI는 사용자 승인에 따라 필수 gate로 대체한다.

## 미해결
원격 PR 메타는 root의 조회 전달값과 로컬 SHA 일치로 확인했다. 블로그 원본은 root 제공 경로의 28편으로 확인했다. CI/독립 검증/병합 전에는 D-073을 닫지 않는다.

# D-091

## 명제
ADR-0031/0032와 현재 검증 안내가 과거 기록, 현재 구현, 현재 측정의 범위를 구분하지 않거나 서로 모순되면 미완이다.

## 작업 항목
- [x] P1. ADR Update Log에 ShedLock 복원 조작, 만료 시각 입력과 전역 시계 제어의 차이, 당시/현재 E2E 시간 측정 범위를 기록한다.
- [x] P2. 현재 검증 안내에서 해당 동작과 측정 범위를 일치시키고 문서 검사를 통과한다.
- [x] P3. E2E 복원 시나리오 docstring이 실제 ShedLock 해제인 `lock_until` UPDATE를 설명하도록 바로잡는다.

## 검증
ADR-0031 D2-3와 `scripts/saga-e2e-smoke.sh`의 실제 UPDATE 및 `scripts/e2e/saga_e2e.py` docstring을 대조한다. run 36338959413 단계 합계 및 run 38991415193 시나리오 잡 wall time을 원본 로그와 대조한다. scenario_e의 저장 만료값 변경이 전역 시계 제어라고 읽히는 문구가 남으면 실패다.

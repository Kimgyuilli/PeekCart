# task-d027-rationale-split

## 명제
`/plan`·`/work`·`/ship` 커맨드 본문에 실측 수치·사건 이력 같은 근거 서술이 남아 매 호출 컨텍스트에 실리면 미완이다.
규칙 문장, 절 번호, 코드 블록이 하나라도 바뀌거나 옮긴 근거가 원문 그대로 보존되지 않아도 미완이다.

## 작업 항목
- [x] P1. 근거 서술을 `docs/conventions/harness-rationale.md` 로 원문 그대로 옮기고, 원래 자리에는 규칙과 한 줄 포인터만 남긴다 (`plan.md`·`work.md`·`ship.md`, 18절)
- [x] P2. 옮긴 줄이 새 문서에 모두 있고 제목 줄은 바뀌지 않았는지 검사한다. 이동 한 번에만 필요한 검사라 스크립트는 레포에 두지 않는다
- [x] P3. 크기 변화를 기록한다. 46,556B → 43,219B (plan 18,477→17,055 · work 13,870→12,940 · ship 14,209→13,224), 3.3KB(7%) 감소

## 검증
- 제목 줄(`^#`) 목록이 변경 전후 동일하다. 외부 참조(`.agents/skills/*` 의 section 번호, `writing.md` 의 `work.md §9`, D-040 의 `work.md §8`)가 여기에 기댄다 → 통과
- 커맨드에서 삭제된 모든 비어 있지 않은 줄이 근거 문서에 그대로 있다 → 통과. 근거 문서에서 한 줄을 지우자 검사가 그 줄을 짚어 실패했다

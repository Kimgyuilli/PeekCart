# D-117 — 루트 README 포트폴리오 개편

기준: 2026-10-27, main `4868373c`. 출발점은 2026-10-22 세션의 README 꾸미기 논의(레퍼런스 분석, 구성 추천, 대표 사례 후보)다.
그 세션은 측정 수요를 D-078 에 넣는 쪽으로 흘러가 구성 논의가 저장소에 남지 않았다. D-078 ⑨ 와
`docs/plans/done/D-078-latency-metrics.md` 는 측정 쪽만 담는다. 이 문서가 그 논의와 2026-10-27 결정을 남긴다.

## 명제

다음 중 하나라도 성립하면 미완이다.

- README 첫 화면(제목부터 결과 수치 표까지)에 결과 수치가 없다. 또는 수치마다 시점·조건·근거 링크가 붙어 있지 않다.
- README 의 수치 가운데 §근거 수치 표에 없는 값이 있거나, 표가 가리키는 원문과 다른 값이 있다.
- 미해결 수치가 실렸다. 열린 행 D-110~D-115 의 값(사가 왕복 지연, DLQ 비율과 허용 범위, 재고 원장 불일치 등)과
  "현재 한계" 절이 해당한다.
- 분산 락을 코드에서 지웠다고 읽히는 문장이 있다. 재고 경로에서 뺐을 뿐 정의(`common` 의 `DistributedLockManager`·
  `RedissonConfig`)는 남아 있다.
- 아키텍처 다이어그램의 서비스·토픽 관계가 현재 코드(`@KafkaListener` 토픽, outbox 발행 상수)와 다르다.
- README 의 상대 링크나 이미지 경로 가운데 추적 파일이 아닌 것이 있다.
- git hook 설정 안내(`git config core.hooksPath .githooks` 와 훅 표)가 빠졌다.

## 결정 (2026-10-27)

- 방향은 2026-10-22 안이다. README 는 입구다. 위쪽은 한 줄 요약, 배지, 결과 수치 표, 아키텍처 다이어그램, 모놀리식에서
  MSA 로의 비교 표다. 아래쪽은 대표 사례를 편마다 문제·결정·수치 3~5줄로 쓰고 ADR·증적으로 링크한다. hook 안내는 맨 아래
  "개발 환경" 절로 내린다.
- 대표 사례는 A·B·C·D 4편이다. E 는 결과 수치 표와 캡처로, F·G 는 개선 이력 표로 줄인다.
- 미해결 수치는 싣지 않는다. "현재 한계" 절을 두지 않고, 열린 작업은 문서 안내 표의 `docs/TASKS.md` 링크로만 가리킨다.
  그래서 C 는 해결된 product 쪽(발행 대기, 만료 취소)만 쓰고 사가 왕복 지연은 쓰지 않는다. B 는 정합성만 쓰고 DLQ 비율은
  쓰지 않는다.
- 분산 락 잔존 코드는 README 문구로만 맞춘다. 삭제 여부는 `docs/progress/PHASE6.md` 이월 판단 항목에 그대로 둔다.
- 기본값(사용자가 따로 정하지 않은 것): 다이어그램은 mermaid 로 그린다. 캡처는 증적 경로를 그대로 링크하고 복사하지
  않는다. 배지는 shields 정적 배지와 CI 상태 배지, 문체는 한국어다.
- 문체는 `../blog` 의 `blog-post-pipeline` humanize 절차(humanize-korean, `guard:rewrite`, `lint:post`, 체크리스트)로
  검사했다(run `2026-10-27-001-66b9`, light, 위험도 low). 사용자 결정으로 ADR 번호(`lint:post` internal-id 12건)는 README 의
  탐색 링크라 두고, 나머지 지적은 모두 반영한다. humanize 가 지운 쉼표 가운데 긴 문장에서 주어가 바뀌는 8곳은 체크리스트
  규칙대로 남긴다.
- 캡처는 E 의 HPA Current Replicas(`loadtest/reports/2026-10-24/grafana/d078-hpa-e-hpa-pod-resources-p4.jpg`)와, C 의
  2026-10-24 contend r3 Outbox 발행률(`loadtest/reports/2026-10-24/grafana/d078-5-drain-contend-r3-saga-p2.jpg`) 두 장을 쓴다.
  발행률 그래프는 사용자 결정(2026-10-27)으로 더했다. 재고 서비스 발행률이 초당 20건 근처에서 더 오르지 않는 모양이 본문
  문장과 맞고, 고치기 전 상태라 미해결 정보가 없다. 캡션에는 본문에 이미 있는 수치만 쓴다. C 의 Outbox backlog 한 쌍은
  2026-10-26 쪽에 미해결인 order backlog 가 함께 보여서 쓰지 않는다. A 는 남은 캡처가 없고, B 의 Grafana 패널은 싣지 않기로
  한 DLQ 유입을 보여 줘서 쓰지 않는다. Pod CPU 패널은 선이 15개라 README 폭에서 읽히지 않는다.

# D-101: 현재 아키텍처 트리와 역사 참조 정정

## 명제

현재 구조가 없는 루트 `src/`·모놀리스 배포 경로를 가리키거나 ADR의 과거 줄번호를 현행 위치로 오인할 수 있으면 미완이다.

## 코드 검증

기준 코드 `be535c57`: `settings.gradle`은 공유 모듈 5개와 도메인 서비스 5개, gateway를 포함한다. root는 소스 없는 aggregator다. Kustomize base는 `namespace/namespace.yml`, 6개 서비스와 두 공개키 ConfigMap 디렉터리를 참조한다. Service는 각 `deployment.yml`에 함께 있고 HPA는 GKE overlay에 있다. ADR-0010의 L95-164는 `787f74e9`, ADR-0012의 L174-382는 `691b2237`에서 원문과 대조했다.

등급 S: 문서의 현재 위치와 역사 탐색 경로만 보정한다. 모듈·배포 계약·결정을 변경하지 않아 새 ADR은 필요 없다.

## 작업 항목

- [x] P1. docs/02 §12를 현재 배포/모듈 트리로 정정하고 기존 배포 절차와 역사 탐색 경로를 유지한다.
- [x] P2. ADR-0010/0012 본문을 보존하고 Update Log에 실제 과거 blob과 현행 절 링크를 추가한다.
- [x] P3. 모든 현행 트리 경로와 링크를 실제 파일/heading에 대조하고 오래된 경로를 재주입하면 검사가 실패하는지 확인한다.

## 검증

현재 트리의 파일·디렉터리를 filesystem과 대조하고 `src/`, `k8s/base/services/peekcart/`, 없는 `order-service/service.yml`·`hpa.yml`을 현재 경로 목록에 주입한 음성 대조군이 실패하는지 확인한다. 역사 링크는 해당 git blob의 실제 줄 내용을 대조하며 ADR 기존 본문과 배포 명령의 보존을 diff로 확인한다. `git diff --check`, grade/preflight/consistency와 커밋·PR writing lint를 실행한다. 전체 테스트는 PR 전체 CI로 확인한다.

## 미해결

이벤트 다이어그램의 기존 4토픽 골격은 이미 역사 범위를 명시하고 있어 이번 범위 밖이다. K8s 실제 apply·GKE 작업·로컬 전체 Gradle 테스트를 실행하지 않는다. TASKS/PHASE/ADR 인덱스 완료 갱신은 root가 관리한다.
